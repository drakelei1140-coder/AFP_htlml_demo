# CID / SID 审核流程需求说明（评审稿）

> 范围说明：本文件仅记录业务流程需求，不包含本期 demo 代码逻辑实现。

## 1. 适用对象与目标

- 对象：企业（CID）与商铺（SID）新建审核流程。
- 目标：统一 OPS + 风控流程，明确评分、人工调整、审批分支、第三方审核触发规则与快照留痕要求。

## 2. 状态定义（统一状态池）

审核相关状态定义为：

1. 待审核
2. 基础资料审核
3. 风控核查
4. 风控初审
5. 风控中审
6. 总经理审核
7. 待第三方审核
8. 审核通过

补充说明：
- 不新增“驳回/退回补件”等终态。
- 风控拒绝后，数据流转到“取消签约企业”（当前 demo 暂未实现该功能，仅记录需求）。

## 3. 总体流程（CID 与 SID 通用骨架）

主流程骨架：

`待审核 -> 基础资料审核 -> 风控核查 ->（按最终风险等级进入审批链）->（按通道规则决定是否进第三方）-> 审核通过`

其中：
- “风控核查”是风控人员核对资料与结果的步骤，不等同于审批节点。
- 风控核查后，按最终风险等级进入审批链路。

## 4. CID（企业）评分与审批流程

### 4.1 评分模型来源与字段要求

- 旧系统无 CID 概念，历史风控评分基于 MID 字段。
- 新系统要求：用于风险评分的字段，在 CID 数据模型中均可获取（以“企业选择 payment 后的字段集”为当前 demo 的最全字段基准）。

### 4.2 评分触发时机

- 评分必须在进入“风控核查”前完成（实时计算）。
- 风控核查人员据此进行二次确认。

### 4.3 风控核查人工调整规则

- 风控核查人员可手动修改“最终风险等级”，并必须填写修改理由。
- 人工修改不会覆盖评分引擎原始计算结果。
- 后续审批流程以“人工定义的最终风险等级”为准。

### 4.4 风险等级与审批链映射

- 低风险：风控初审
- 中风险：风控初审 + 风控中审
- 高风险：风控初审 + 风控中审 + 总经理审核

说明：
- 此处“初/中/高级”指风险等级结果，不是状态名。
- 状态名中不设置“风控高级审核”。

## 5. SID（商铺）复用评分与简化审批规则

### 5.1 SID 与 CID 行业/MCC一致

当 SID 的“行业 + MCC”与 CID 一致时：
- 采用“复用评分但仍走简化审批”的模式；
- 流程节点定义仍保留，但命中规则后可自动流转完成简化审批；
- 不等于物理删除流程节点。

### 5.2 同 CID 下已通过 SID 的行业/MCC一致

当新建 SID 与同一 CID 下任意已通过 SID 的“行业 + MCC”一致时，可触发简化审批（免审策略候选），但需同时满足：

1. 前端勾选承诺协议（前端团队负责）；
2. 系统校验“新 SID 行业 + MCC”与目标已通过 SID 确实一致。

不设置有效期限制。

### 5.3 SID 修改资料场景

- 当 SID 修改资料且行业/MCC不变：仅免风控，仍需基础资料审核。

## 6. 第三方审核状态触发规则（CID / SID 均适用）

当创建 MID 选择 payment 通道时（可多选）：

- 若所选通道中任意一个需要第三方 KYC：
  - 内部审核（含总经理审核，如适用）完成后进入“待第三方审核”。
- 若所选通道全部不需要第三方 KYC：
  - 跳过“待第三方审核”，直接进入“审核通过”。

补充：
- “总经理审核”与“待第三方审核”为两个独立状态。
- 第三方审核是否需要，由系统通道配置控制。

## 7. 地区级开关（本期仅记录，不实现）

针对“SId命中行业/MCC一致后是否可自动简化审批”需支持地区维度开关：

- 开启：命中规则后可走简化审批。
- 关闭：即使命中规则，也走完整审批流程（按最终风险等级判定）。

说明：
- 开关功能本期不做，仅作为需求约束记录。

## 8. 香港评分规则（基线）

以下规则作为当前评审基线，后续可由合规策略配置扩展。

### 8.1 分项评分

1. 公司类型评分：
   - 有限公司=1分；合伙/个人（合法经营/实际经营）=2分；其他（非属法团）=10分。

2. 成立地/注册地评分：
   - 香港=0分；非香港且非高风险/非受制裁=3分；高风险非受制裁=6分；受制裁地区=999分。
   - 受制裁国家、高风险国家名单由合规部门提供，系统需支持名单更新。

3. 公司结构评分：
   - 1层=1分；2层=1分；3层=2分；4层或5层及以上=4分。

4. 单月交易平均金额评分：
   - <HK$500=0分；HK$500~1,999=1分；HK$2,000~9,999=3分；>=HK$10,000=10分。

5. 业务交付方式评分：
   - 货到付款=1分；预付款<10%=5分；预付款>10%=15分。

6. 业务营运年期评分：
   - >5年=1分；2-5年=2分；<2年=4分。

7. 年营业额评分（平均每月营业额*12）：
   - <HK$150,000=0分；HK$150,000~700,000=1分；HK$700,000~2,500,000=2分；>HK$2,500,000=4分。

8. 董事/实益拥有人信息评分：
   - 同时采集“董事”与“持股>=25%实益拥有人/股东”；分别评分后取最高分计入总分。
   - 自然人维度：国籍、居住地、姓名合规校验。
   - 公司维度：成立地、营运地。

### 8.2 计算与优先级

1. 总分=全部分项得分之和。
2. 地域类评分优先级：受制裁(999) > 高风险(6) > 普通(3/0)；同主体多个地域字段取最高分。
3. 特殊处理：命中受制裁信息时，总分直接标记高风险并触发人工复核。
4. 空值处理：CRM字段为空时按该项“默认最高风险分”计算。

### 8.3 评分结果应用

- 低风险：0~10分（自动准入，常规额度审批）
- 中风险：11~30分（人工复核关键信息后准入）
- 高风险：>=31分或存在999分项（拒绝准入或专项审批）

备注：在本流程中，审批节点走向以“风控核查后的最终风险等级”决定。

## 9. 留痕与快照要求

每次关键判断均需快照留存，至少包括：

- 评分输入快照（字段值、名单版本、地区配置）
- 评分输出快照（各分项得分、总分、原始风险等级）
- 人工调整快照（调整后等级、调整人、时间、理由）
- 路由判定快照（是否命中SID复用规则、是否命中第三方审核通道）
- 流程节点快照（每个状态进入/离开时间、处理人）
